# Iron Wilds

一款第一人称 3D 机甲战斗游戏。玩家驾驶 H-09 Field Walker 进入盆地，恢复中继线并击败六台自动哨兵；也可以离开机甲，搬运动力核心和弹药箱。

## 玩法

- 手机：游戏检测到触控设备后显示方向键、射击、喷射和交互按钮。
- 桌面：`WASD` 移动，鼠标观察和瞄准，鼠标左键射击。
- `1` / `2` / `3`：切换机炮、制导导弹和迫击炮。
- `Space`：启动跳跃喷射；`E`：进出机甲；`G` / `I` / `R`：搬运、安装和补充物资。
- `Esc`：暂停；`M`：选择目标；`F`：切换反应堆。

## 运行方式

通过静态服务器或 GitHub Pages 打开 [index.html](index.html)。页面从 jsDelivr 加载 Three.js 0.169.0，因此首次运行需要网络和 WebGL 支持。
