# THUNDERFALL · 雷霆战机 · 天穹远征

一款支持手机触控、鼠标和键盘的原创纵向弹幕射击游戏。选择三种不同战机之一，穿越五大空域，躲避漂移弹与激光，拾取四色武器并挑战多阶段 Boss。

## 玩法

- 手机或鼠标：在战场任意位置按住拖动，战机自动开火。
- 键盘：`WASD` 或方向键移动，`Shift` 精密低速。
- `Space`：震荡炸弹；`E`：雷霆爆发；`P` / `Esc`：暂停。
- 完整战役至少包含 10 分钟有效战斗，也可以选择任意一关演练。
- 声音由 Web Audio 实时合成，最高分和偏好只保存在当前浏览器。

## 运行方式

通过静态服务器或 GitHub Pages 打开 [index.html](index.html)。九个运行文件全部保存在当前目录，没有 CDN、登录、API Key 或外部素材依赖。
