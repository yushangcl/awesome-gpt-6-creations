# 汴京入梦 · 千门长卷

一座以《清明上河图》为灵感的动态 3D 微缩汴京。长卷从春郊、漕运、虹桥一路延伸至城阙与灯市，置于宋式宫殿展厅中，并可在春昼、黄昏和灯火通明的夜游之间切换。

## 创作说明

- 通过 GPT-6 在 Codex 中多轮创建、评审和迭代。
- 采用单文件网页形式，Three.js、程序化材质、Shader、CSS 和交互逻辑均已内嵌。
- 城市由程序化几何构成，包含 306 座建筑、650 名人物、26 艘船、150 株树与 12 辆牛车。
- 这是基于北宋汴京市井意象的艺术演绎，不作为历史复原。

## 玩法

- 拖动屏幕或鼠标：旋转视角。
- 双指或滚轮：缩放视角。
- 双击场景：进入清晰近景。
- 拖动底部长卷：连续游览五个区域。
- `春昼`、`黄昏`、`夜游`：切换场景时辰。
- 桌面端按住 `Shift` 拖动：平移镜头。
- 桌面端可使用方向键、`+`、`-`、`R`、`D`、`F` 和空格键操作。

## 技术说明

- 单文件 HTML、CSS、JavaScript 与 GLSL。
- Three.js r160.1 与全部运行资源内嵌。
- WebGL 程序化长卷、实例化建筑与灯火、LOD、动态河水和电影镜头后处理。
- 近景自动关闭景深模糊，以保留人物和建筑细节。

## 设备建议

- 推荐使用启用图形加速并支持 WebGL 的现代 Chrome、Edge 或 Safari。
- 支持手机竖屏与桌面宽屏；手机端使用触控手势和大尺寸按钮。
- 场景内容较丰富，较旧设备首次展开可能需要稍候。
